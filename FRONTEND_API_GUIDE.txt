==============================================================================
   MISTER MINIT - FRONTEND (FE) DASHBOARD & STATS INTEGRATION GUIDE
==============================================================================

Welcome! This guide explains how to connect your Frontend dashboard to the 
Mister Minit backend analytics APIs.

All endpoints support CORS, accept JSON, and are live on your backend.

------------------------------------------------------------------------------
1. BASE URL
------------------------------------------------------------------------------
Production: https://www.mister-minit.omnisuiteai.com
Local Dev:  http://localhost:3060

Swagger Interactive Docs: https://www.mister-minit.omnisuiteai.com/api

==============================================================================
2. QUICK SUMMARY OF APIS FOR YOUR SCREENS
==============================================================================

Screen Element                     | API Endpoint to Call
-----------------------------------|------------------------------------------
1. Overview - Store Selector       | GET /stats/stores
2. Overview - KPI Cards & Charts   | GET /stats (or GET /stats?storeId=...)
3. Overview - Store Comparison     | GET /stats/by-store
4. Overview - Live Audit Feed      | GET /logs/recent
5. SMS Concierge (Live Threads)    | GET /sms-threads/live
6. Store Configs                   | GET /store-config
7. 3CX Call Logs (Pilot Stores)    | GET /cdr/logs (or GET /cdr/logs?storeId=...)
8. Suppression & Opt-outs          | GET /suppressions & GET /suppressions/opt-outs

API 1: Get Stores List (For Dropdown / Filter Selector)
------------------------------------------------------------------------------
Endpoint: GET /stats/stores
Description: Call this once when the dashboard loads to populate your 
"Select Store" dropdown menu.

Example Response:
[
  {
    "storeId": "6a9ea2774d7dcfbae9cc58b6",
    "storeName": "Marion",
    "did": "0872286100",
    "isActive": true
  },
  {
    "storeId": "6a9ea2774d7dcfbae9cc58b7",
    "storeName": "Westfield Doncaster",
    "did": "0398485555",
    "isActive": true
  }
]

FE Implementation Tip:
Add an "All Stores" option at the top of your dropdown with value = "".

API 2: Main Stats & Analytics
------------------------------------------------------------------------------
Endpoint: GET /stats
Query Parameters (Optional):
  - storeId    : (string) MongoDB ID of store (e.g. ?storeId=6a9ea2774d7dcfbae9cc58b6)
  - did        : (string) Phone number of store (e.g. ?did=0872286100)
  - startDate  : (ISO date) e.g. ?startDate=2026-01-01
  - endDate    : (ISO date) e.g. ?endDate=2026-12-31

* If you do NOT pass storeId/did, it returns stats for ALL STORES combined.
* If user selects a store in your dropdown, pass ?storeId=... to get that store only.

------------------------------------------------------------------------------
Where to display each field in your UI:
------------------------------------------------------------------------------

A. TOP KPI STAT CARDS:
   - Total Inbound Calls:  telephony.totalInboundCallVolume
   - Missed Calls:         telephony.missedCalls  (with telephony.storeMissedCallRate %)
   - Recovered Inquiries:  conversions.recoveredInquiries (Total SMS threads opened)
   - Customer Replies:     conversions.customerReplies (with conversions.customerEngagementRate %)
   - Bookings Captured:    conversions.bookingsCaptured (with conversions.bookingConversionRate %)
   - Store Visits:         conversions.footTrafficConversions (Customers confirmed visiting store)

B. CHARTS:
   - Service Demand (Bar/Pie Chart):
     Use conversions.serviceDemandBreakdown (e.g. Car Keys, Shoe Repair, etc.)
   - Conversation Funnel (Funnel Chart):
     Missed Calls -> Recovered Inquiries -> Customer Replies -> Bookings Captured
   - Conversation Status (Donut Chart):
     Use conversions.threadStatusDistribution

C. SAFETY & COMPLIANCE WIDGET:
   - Deduplication Filtered: aiSafetyQualityControl.deduplicationPrevented (No double-messaging)
   - Landlines Filtered:     aiSafetyQualityControl.landlineFiltering (Saved carrier SMS cost)
   - Answered Calls Safe:    aiSafetyQualityControl.answeredCallsFiltered (Customer answered)
   - Opt-Out Rate:           complianceAndRetention.optOutRate % (Legally compliant)

5. MODULE: SMS CONCIERGE (LIVE THREADS & ONGOING CHATS)
==============================================================================
Endpoint: GET /sms-threads/live
Description: Returns active, ongoing SMS threads that are NOT closed and NOT 
suppressed. Shows the current thread state and the full ongoing chat history 
between the customer and the AI concierge.

Query Parameters (Optional):
  - storeId: (string) Filter by Store ObjectId
  - did    : (string) Filter by Store DID phone number
  - search : (string) Search customer mobile number (e.g. ?search=0412)
  - limit  : (number) Number of items per page (default: 50)
  - skip   : (number) Pagination offset (default: 0)

Example Response:

6. MODULE: 3CX CALL LOGS (PILOT STORE CALL RECORDS)
==============================================================================
Endpoint: GET /cdr/logs
Description: Returns 3CX telephony call records STRICTLY filtered to those stores 
configured in StoreConfig. Automatically enriches every record with the storeName, 
storeId, and whether the call was a missed call or answered.

Query Parameters (Optional):
  - storeId  : (string) Filter to specific store
  - did      : (string) Filter to specific store DID
  - isMissed : ("true" | "false") Filter missed calls vs answered calls
  - search   : (string) Search caller number
  - startDate: (ISO date string)
  - endDate  : (ISO date string)
  - limit    : (number) Default: 50
  - skip     : (number) Default: 0

Example Response:
{
  "total": 42,
  "limit": 50,
  "skip": 0,
  "logs": [
    {
      "id": "66f023bc9c812d45a0b98765",
      "callId": "call-10023",
      "timestamp": "2026-09-22T08:15:00.000Z",

      "timeAnswered": "",

      "duration": "00:00:05",

7. MODULE: SUPPRESSION & OPT-OUTS
==============================================================================
API 7A: Suppressed Call Events
Endpoint: GET /suppressions
Description: Returns all suppressed telephony calls that did not trigger an SMS 
(e.g. not a mobile, not a missed call, internal extension, opted out, etc.).

Query Parameters (Optional):
  - reason   : (string) e.g. "not_mobile", "not_missed_call", "internal_extension", "opted_out", "dedup", "not_a_pilot_store"
  - storeId  : (string) Filter by store
  - search   : (string) Search caller number
  - startDate: (ISO date string)
  - endDate  : (ISO date string)
  - limit    : (number) Default: 50
  - skip     : (number) Default: 0

Example Response:
{
  "total": 12,
  "limit": 50,
  "skip": 0,
  "events": [
    {
      "id": "66f034cd9c812d45a0b54321",
      "callerNumber": "0298765432",
      "did": "0872286100",
      "storeId": "6a9ea2774d7dcfbae9cc58b6",
      "storeName": "Marion",
      "callId": "call-10024",
      "suppressedReason": "not_mobile",
      "createdAt": "2026-09-22T08:20:00.000Z"
    }
  ]
}

API 7B: Customer Opt-Outs
Endpoint: GET /suppressions/opt-outs
Description: Returns the list of mobile numbers that have opted out via STOP 
or LLM intent.

Query Parameters (Optional):
  - search   : (string) Search caller mobile number
  - source   : ("keyword" | "llm_detected")
  - startDate: (ISO date string)
  - endDate  : (ISO date string)
  - limit    : (number) Default: 50
  - skip     : (number) Default: 0

Example Response:
{
  "total": 2,
  "limit": 50,
  "skip": 0,
  "optOuts": [
    {
      "id": "66f045de9c812d45a0b65432",
      "callerNumber": "+61412999888",
      "keyword": "STOP",
      "source": "keyword",
      "threadId": "66f012ab9c812d45a0b12345",
      "optOutAt": "2026-09-22T08:30:00.000Z",
      "createdAt": "2026-09-22T08:30:00.000Z"
    }
  ]
}

API 7C: Suppression & Opt-Outs Summary
Endpoint: GET /suppressions/summary
Description: Returns aggregated counts for top summary cards.

Example Response:
{
  "totalSuppressed": 15,
  "byReason": {
    "not_mobile": 8,
    "not_missed_call": 5,
    "dedup": 2
  },
  "totalOptOuts": 2
}
